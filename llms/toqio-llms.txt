- [Get Transactions](https://platform.toq.io/reference/gettransactionsusingget.md): Returns a paginated list of transactions for the customer, filtered by the provided query parameters (account, company, dates, status, amount range, currency, etc.). Use this endpoint to retrieve the transaction history that powers statements, expense lists and reconciliation views.
- [Get Transaction](https://platform.toq.io/reference/gettransactionusingget.md): Returns the full detail of a single transaction by its identifier, including the source/beneficiary accounts, amounts, status, attached invoice metadata and any associated expense or category information.
- [Cancel Transfer](https://platform.toq.io/reference/canceltransferusingdelete.md): Cancels a previously created transaction that has not yet been settled by the bank (e.g. a pending or scheduled transfer). Once the underlying transfer is in flight or has settled, the transaction can no longer be cancelled through this endpoint.
- [Get Bank Payment Schemes](https://platform.toq.io/reference/getbankpaymentschemesusingget.md): Returns the list of bank payment schemes (SEPA, SWIFT, UK Faster Payments, FX, etc.) available for sending the given amount from the source account to the beneficiary account through the specified provider. The returned code should be passed as the bankPaymentScheme when calling Create Transaction.
- [Generate statement](https://platform.toq.io/reference/generatestatementusingget.md): Generates a PDF payment statement for a single transaction in the requested locale and returns it base64-encoded. Only applies to card payments and inbound/outbound bank transfers; other payment types are rejected with 417.
- [Get Quote For Currency Pair](https://platform.toq.io/reference/getquoteforcurrencypairusingput.md): Requests an FX quote from the specified provider for converting between two currencies. Returns the indicative rate, fees and the quote identifier that should be referenced when issuing the corresponding FX payment.
- [Create transaction](https://platform.toq.io/reference/create-transaction.md)
- [Create Transaction](https://platform.toq.io/reference/createtransactionusingpost.md): Issues a payment on behalf of a client. Supports internal transfers, SEPA, SWIFT, UK Faster Payments and FX payments depending on the source account provider and currency. The bank payment scheme is required (except for FX); call the bankPaymentSchemes endpoint first to discover which schemes are available for the chosen source/beneficiary pair.
- [Get account fees](https://platform.toq.io/reference/getnewaccountfees-1.md): Allows to get the fees of an account
- [Get card fees](https://platform.toq.io/reference/getcardfees-1.md): Allows to get the fees of a card. For both virtual and physical cards
- [Transaction fee](https://platform.toq.io/reference/transactionfeeusingpost.md)
- [Get beneficiaries](https://platform.toq.io/reference/getbeneficiariesusingget.md): Returns the list of beneficiaries registered for a client. All filter query parameters (accountId, sourceCurrency, visible) are optional: omit them to retrieve every beneficiary the client can pay; pass them to narrow the result to a specific source account or currency. By default only visible (non-hidden) beneficiaries are returned — pass visible=ALL or visible=FALSE to include or restrict to hidden ones.
- [Create beneficiary](https://platform.toq.io/reference/createbeneficiaryusingpost.md): Creates a new beneficiary for the given client. The beneficiary can be either external (identified by account details such as IBAN/account number plus bank details) or internal (linked to another Toqio account). Once created the beneficiary can be used as the destination of a payment via the Create Transaction endpoint.
- [Get beneficiary](https://platform.toq.io/reference/getbeneficiaryusingget.md): Returns the full detail of a single beneficiary by identifier, including bank account details, address, asset type and visibility flags.
- [Update beneficiary](https://platform.toq.io/reference/updatebeneficiaryusingput.md): Updates the details of an existing beneficiary. Only profile fields (name, address, city, postal code, country and visibility) can be edited. Bank account details captured at creation (currency/asset type, bank country, IBAN, account numbers, sort/routing codes, BIC/SWIFT and the Currencycloud-specific identifiers) are immutable: they are marked read-only and any value supplied for them is ignored, the stored value is preserved. To change bank details, delete the beneficiary and create a new one.
- [Delete beneficiary](https://platform.toq.io/reference/deletebeneficiaryusingdelete.md): Removes a beneficiary from the client's address book. The beneficiary is logically deleted and will no longer appear in Get Beneficiaries; historical transactions that referenced it remain unaffected.
- [Get or create internal beneficiary](https://platform.toq.io/reference/getinternalbeneficiaryusingpost.md): Returns the internal beneficiary pointing to the given Toqio account, creating it on the fly if one does not yet exist. Internal beneficiaries are used for transfers between two accounts that both live on Toqio (intra-platform payments) and avoid duplicating bank details across the address book.

- [Pay payment request](https://platform.toq.io/reference/payrevenue.md): This endpoint allows merchants to make immediate payments for invoice payment requests. Once the payment is made successfully, the status of the corresponding request will be updated to PAID.

- [Unfreeze company](https://platform.toq.io/reference/unfreezecompanyusingput.md): Allows to unfreeze a company
- [Reject company](https://platform.toq.io/reference/rejectclientusingput.md): This endpoint allows rejecting a company. Only companies under 'Onboarding', 'Live' and 'Quarantine' status can be rejected
- [Delete company](https://platform.toq.io/reference/deleteclientusingdelete.md): This endpoint allows deleting a company. Only companies under 'Lead' and 'Rejected' status can be rejected
- [Get user](https://platform.toq.io/reference/getuserusingget.md): Allows to get the details of a given user
- [Create user](https://platform.toq.io/reference/inviteuser.md): Allows to create a user under a client
- [Get card fees](https://platform.toq.io/reference/getcardfees.md): This endpoint is deprecated. You should use <a href="https://docs.toq.io/reference/getcardfees"><u>Card Fees</u></a>
- [Generate customer key](https://platform.toq.io/reference/customerkey.md): Allow to generate a key to encript the credentials data. You must keep it in a secure place as we do not have access to it. If you lose it, you will need to contact the support team to generate a new one.
- [Create username](https://platform.toq.io/reference/usercredentialsusername.md): Allow the user to set up their own username
- [Create security questions](https://platform.toq.io/reference/usercredentialsecurityquestion.md): Allow the user to set up their own security question answers. This is only required to Modulr customer
- [Create security code](https://platform.toq.io/reference/setcredentialssecuritycode.md): Allow the user to set up their own security code.
- [Create password](https://platform.toq.io/reference/setuserpassword.md): Allow the user to set up their password.
- [Activate card](https://platform.toq.io/reference/activatecard.md): Activates (unfreezes) a previously suspended card so it can be used again for transactions. The request body must include the card activation token issued during card delivery.
- [Execute Four-Eyes Payment](https://platform.toq.io/reference/executefoureyespaymentusingpost.md): Executes a previously created transaction that was held for four-eyes approval. The referenced transaction must be in pending-approval status; once executed, the underlying payment is sent to the bank provider and the transaction transitions to the standard payment lifecycle.
